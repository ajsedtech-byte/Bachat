Seller dashboard

Run daily seller work in one place.

The seller dashboard is the operating desk for Bachat sellers. It helps shops review requests, send accurate quotes, accept orders, track payment and delivery readiness, and keep support context connected to the customer journey.

Quote, accept, fulfill.

The dashboard should be checked like a daily counter because missed requests and outdated order states directly affect buyer trust.

What sellers manage inside the dashboard

A seller uses the dashboard to turn buyer demand into confirmed fulfillment. The first responsibility is to review incoming requests carefully and avoid quoting items that are unavailable or unclear. The second responsibility is to keep accepted orders updated so buyers and support do not need to guess the status. The third responsibility is to respond quickly when a delivery, payment, or product issue appears.

Recommended daily routine

Morning review

Check new requests, pending quotes, active orders, KYC alerts, and unresolved support notes.

Order readiness updates

Mark orders accepted, packed, ready, handed off, or fulfilled as soon as those states are true.

End-of-day cleanup

Review failed orders, buyer questions, out-of-stock products, delayed deliveries, and any quotes that need correction.
